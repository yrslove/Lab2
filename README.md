# Лабораторна робота № 2

Програми для роботи з файлами й каталогами в Linux. Перша утиліта зчитує заданий фрагмент файлу та виводить його в термінал або записує в інший файл. Друга відображає вміст каталогу з можливістю перегляду прихованих об'єктів і додаткових відомостей про файли. Обидві програми написано мовою C, для обробки параметрів використано `getopt_long`.

Для збирання потрібні GCC та GNU Make. Команда `make`, виконана в каталозі `task1` або `task2`, створює відповідну програму в підкаталозі `bin`. Команда `make clean` видаляє результати компіляції.

```sh
cd task1
make
./bin/readpart -p 0 -c 12 -n pryklad.txt
./bin/readpart --position 0 --count 20 --output uryvok.txt pryklad.txt
cd ../task2
make
./bin/dir -l .
./bin/dir --all --long ..
```

Опції `-h` та `--help` виводять довідку для кожної програми. Якщо позицію та кількість байтів не зазначено, перша програма читає файл повністю. Друга програма за відсутності шляху переглядає поточний каталог. Некоректні параметри або помилки файлової системи повідомляються через стандартний потік помилок.
